# Hobbits

## What is this project about?
This is a habit tracker. Project to restore love for programming and more importantly build a habit.
Makes sense.
Also learn basics of React.

## How is it going to look like?
Ideas from Claude (add my ideas later):
- Create categories: programming, exercise, cooking, writing, Japanese, reading.
- Add habits or sessions under each category.
- Log time spent, such as 90 minutes programming or 30 minutes running.
- Set a daily minimum for each habit.
- See a daily and weekly dashboard.
- Write a short reflection: “What did I build, learn, or struggle with today?”
- View streaks and basic completion statistics.
